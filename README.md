## Overview

SGDBoop is a lightweight desktop utility that receives custom artwork from SteamGridDB's browser extension and applies it directly to Steam library entries — capsule images, hero banners, logos, and icons — for both Steam and manually added non-Steam games. It detects your Steam installation automatically and requires no manual file navigation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SGDBoop** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **One-Click Apply** | Browser extension on SteamGridDB sends artwork to SGDBoop for instant apply |
| **All Artwork Types** | Capsule, hero banner, logo, and icon artwork types for every entry |
| **Non-Steam Games** | Works with manually added non-Steam executables in your library |
| **Auto Detection** | Automatically finds Steam installation path and all library folders |
